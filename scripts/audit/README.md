# scripts/audit — 시그널 검증 스크립트

2026-08-17 정합성 진단에서 쓴 재현 스크립트. **테스트가 아니라 조사 도구**라
pytest 가 수집하지 않는다(`scripts/` 아래라 `testpaths=["tests"]` 밖).

## 실행

```bash
PYTHONPATH=src .venv/bin/python scripts/audit/verify_backtest.py
```

> ⚠️ `PYTHONPATH=src` 를 빼면 **메인 레포에 editable 설치된 패키지**를 임포트한다.
> 워크트리에서 작업 중이면 수정 전 코드를 검증하게 된다. `pytest` 는 `pyproject.toml` 의
> `pythonpath=["src"]` 덕에 신경 안 써도 되지만, 이 스크립트들은 직접 붙여야 한다.

`data/cache/long.parquet`(KB 주간 시계열)가 있어야 한다. 없으면 `.venv/bin/signal fetch`.

## 무엇을 하나

| 스크립트 | 내용 | 소요 |
|---|---|---|
| `verify_backtest.py` | 성적표 적중률의 **base rate**(전체 지역·전체 주 상승률)와 **순열검정**(같은 날짜·무작위 지역 200회) | ~1분 |
| `verify_onset.py` | 성적표는 구간 **종료 후**를 재는데 사용자는 시그널이 **켜져 있는 동안** 산다. 온셋 기준 12/26/52주 수익률 + 시장 대비 초과 + 표본 독립성 점검 | ~3분 |
| `verify_classify_vs_evaluate.py` | 백테스트가 채점하는 규칙(`_classify`)과 화면에 뜨는 규칙(`evaluate`)의 불일치율 | ~1분 |
| `adversarial.py` | 위 결과를 **무너뜨리려는** 반증 시도 — 광역 내 순열, peer 벤치마크, AR(1) 합성 시계열, 거래비용 실행값 | ~5분 |

## 이 스크립트들이 밝힌 것 (요약)

- 시그널은 무작위가 아니다 — 같은 광역 내 순열 대비 리프트 STRONG_BUY **+6.3%p**, BUY **+7.6%p**
- 그러나 **온셋 기준 시장 대비 초과수익은 52주에 +0.25%p** 로, 왕복 거래비용 **4.43%** 의 1/18
- 반면 매도 회피는 **−1.14%p** 로 값어치가 크다
- 높은 상승률(99.3%)의 대부분은 KB 지수의 **평활성**(lag-1 자기상관 0.824)이 만든다.
  다만 적중률 86% 는 AR(1) 합성으로 52~54% 밖에 안 나와 **평활성만으로 설명되지 않는다**

전체 맥락과 판정은 `docs/audit-2026-08-17.md`.
