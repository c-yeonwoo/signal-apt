## 3. 절대 다시 밟지 말아야 할 함정

### 3.1 워크트리에서 검증하는 법 — **이번에 두 번 밟았다**

`.venv` 는 **메인 레포에 editable 설치**(`.pth` 로 `/…/realty-signal-map/src` 추가)돼 있다.
워크트리에서 그냥 돌리면 **메인 레포 코드를 임포트하는데도 "통과"가 뜬다.**

| 상황 | 올바른 방법 |
|---|---|
| `pytest` | 그냥 돌려도 된다 (`pyproject.toml` 의 `pythonpath=["src"]`) |
| `python -c …` · 스크립트 | **`PYTHONPATH=src` 필수** |
| **브라우저 프리뷰 서버** | **프리뷰 도구는 세션이 처음 열린 디렉토리의 `.claude/launch.json` 을 읽는다.** `EnterWorktree` 로 옮겨도 안 바뀐다 |
| 서버가 새 코드인지 확인 | `curl -s localhost:8765/ \| grep -c '<새로 추가한 JS 함수명>'` → **0 이면 옛 코드다** |
| 라우트 존재 확인에 HTTP 코드를 쓰지 말 것 | 미들웨어가 없는 경로까지 전부 401 로 덮는다 |

⚠️ **2026-09-08 에 이걸로 koczip 제거 전 코드가 떠서 403 크롤링이 다시 돌았다.** 즉시 서버를 껐다.
다른 워크트리 코드를 프리뷰하려면 **원래 디렉토리의** `launch.json` 을 절대경로로 고쳐야 하고, **끝나면 되돌려야 한다.**

### 3.2 koczip — 재개 금지

`koczip.com` 이 응답 본문에 **무단 크롤링·스크래핑·복제·저장·재배포 금지**를 명시하고 403 을 준다.
재시도 대상이 아니다. 브라우저 위장 헤더도 제거했다. **서면 허락 없이는 재개하지 않는다.**
코드·라우트·SQLite 테이블·화면 전부 #176 에서 제거됐다.

### 3.3 스냅샷 규율 — 이 프로젝트의 최대 버그 원천

- **기능마다 전용 kv 키.** 공유하면 한쪽이 보여줄 때 다른 쪽 변화가 사라진다.
  브리핑은 '어제 대비'(`briefing_snap:`), 홈은 '이번 주 KB 갱신' — **의도적으로 다르다.**
- **기준점은 보여준/발송한 뒤에만 옮긴다.** 실패 시 옮기면 변화가 유실된다.
- `complex_watch.scan()` 이 기준점을 **인자로 받는** 이유가 이것이다 — 홈과 브리핑이 같은 로직을
  각자의 기준점으로 돌린다.
- 과거 사고: `signal watch`(CLI)와 서버 `_do_refresh` 가 **둘 다** 스냅샷을 당기는데 로그는 서버만
  써서 두 주(07-13·07-20)를 통째로 잃었다. **스냅샷을 당기는 곳은 전부 `snapshots.advance()`.**

### 3.4 캐시 스키마를 바꾸면 `CACHE_VER` 를 올린다

R4 에서 옛 kv 캐시가 살아남아 ★ 관심지역 표시를 **조용히** 무력화했다.

### 3.5 0 에는 이유를 붙인다

'변화 없음' · '비교할 지난주 없음' · '계산 실패' · '조회 원천 불가'가 화면에서 같아 보이면 안 된다.

이걸 '거래 없음'으로 표시하면 매주 조용히 거짓말한다.

### 3.6 롤링 윈도로 증감을 재지 말 것

## 5. 구조적으로 "계단식"인 이유 (고장이 아니다)

다음 세션이 "왜 아직도 잘 안 바뀌지?"라고 물을 때의 답:

- **임계값 양자화** — 등급 = 3표 합산(`engine._classify`). 지수가 0.71 움직여도 표가 안 바뀌면 등급 그대로.

  서울 11개 구가 동일한 69.29(임계값 70 대비 −0.71)를 공유 → 같이 움직이거나 같이 안 움직인다.
- **전세난 표가 사실상 상수** — 94% 충족. 3표 중 1표가 항상 켜져 있으면 해상도가 준다.
