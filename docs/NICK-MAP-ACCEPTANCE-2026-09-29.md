# 지도·Nick 매물분석 수용 현황 (2026-09-29)

## 배포된 기능

- PR #222: 서버에서 선택 매물 ID·권한을 재확인하고, 동일 면적·층 실거래 근거와 매물 리포트/Nick 문맥을 연결했다.
- PR #223: 공식 초등 통학구역 후보와 Kakao 역 도보·저장 직장 경로·주변 시설을 표시 좌표 품질과 함께 분리했다.
- PR #224: 매물 2~3개를 동일 기준으로 비교하고, 개인 매물 권한을 항목별로 검증한다.
- PR #225: 현재 수집분의 대안 및 기존 뉴스 헤드라인 문자열 후보를 보여준다. 직접적인 사업·가격 영향으로 주장하지 않는다.
- PR #226: 사용자가 지도에서 800m 이내 출입구 후보를 지정할 수 있다. 실제 출입구 인증이 아니다.
- PR #227: K-APT 공식 단지명·시군구를 유일하게 매칭한 경우에만 세대수·시공사·사용승인·등록 주차면을 온디맨드로 보여준다.
- PR #228: 확정 매수력 대비 호가를 표시하고, 대안 최대 6건의 직장 통근 안내시간을 요청 시에만 비교한다.

## 자동화된 수용 검사

- 전체 Python·Node 테스트와 360px Chromium UI 회귀 검사.
- 개인 일반매물은 원 소유 계정만 리포트·위치·K-APT·비교·대안을 조회한다.
- 좌표 누락, 학교 경계, 외부 API 부분 실패, K-APT 이름 중복/목록 절단, 매물 전환 시 이전 응답 폐기를 검사한다.
- 핵심 행동 이벤트는 매물 ID, 단지명, 직장 좌표 없이 집계한다. 이벤트별 이용 계정 수는 전환율이 아니다.

## 운영 데이터로 별도 확인할 항목

1. Railway의 공공데이터 키에 [K-APT 단지 목록](https://www.data.go.kr/data/15057332/openapi.do)과 [기본 정보](https://www.data.go.kr/data/15058453/openapi.do) 활용 권한이 있는지 실제 매물 3건으로 확인한다. 권한이 없으면 카드가 `unavailable`로 남는다.
2. 관심 지역 3곳·20개 단지로 정확한 단지 식별, 학구 경계, 복수 출입구, 좌표 누락, 거래 희소, 경로 응답, 휴대전화 조작을 현장 검증한다. 자동 테스트의 합성 데이터는 이 검증을 대신하지 않는다.
3. `매물분석 시작 → 리포트 준비 → 근거 열람 → 비교 → 찜 → 임장 기록`의 건수·이용 계정 추이를 관리자 화면에서 관찰한다. 과금·p95 지연은 운영 계측 후 목표를 조정한다.
4. 서울 정비사업 공개 추진경과는 사업번호별 단계이지만, 현재 매물 단지의 확정 사업번호와 연결되지 않는다. 이름/헤드라인 유사성으로 단지별 호재 단계를 생성하지 않는다. 공식 사업번호 매핑 확보 전에는 `미확인`을 유지한다.
5. 지도 엔진 교체나 자체 타일 운영은 실제 핀 수·렌더 지연·타일/API 비용이 기존 Leaflet의 병목을 보일 때 결정한다. 현재 구현은 단지명+표시 좌표 그룹핑과 뷰포트 목록/핀 제한을 사용한다.

주차면은 주차 가능 여부, 경로 안내시간은 특정 시각의 출퇴근 시간, 통학구역 후보는 배정 학교, 호가와 매수력 비교는 대출 승인을 의미하지 않는다.
