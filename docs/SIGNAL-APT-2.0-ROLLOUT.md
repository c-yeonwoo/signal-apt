# Signal APT 2.0 단계 전환·되돌리기

기존 운영 화면이 이미 2.0 경로를 사용하므로 리포트·발견·선택형 설명 스위치는 기본 `on`이다. 이는 개인 매물 접근권이 아니다. Railway에서 환경변수를 바꾸면 재배포 후 새 로그인/새로고침부터 적용된다.

| 환경변수 | `0`일 때 | 기본값 |
| --- | --- | --- |
| `REPORT_V2_ENABLED` | 새 독립 리포트 API 중지; 지역 패널은 중지 안내, 매물은 기존 결정적 분석 패널로 이동 | `1` |
| `DISCOVERY_V2_ENABLED` | 조건별 발견 API 중지; 버튼은 기본 매물 목록으로 이동 | `1` |
| `CONTEXTUAL_EXPLANATIONS_ENABLED` | 선택형 유료 AI 설명 작업 신규 생성 중지; 근거 리포트는 유지 | `1` |

`0`, `false`, `no`, `off`는 대소문자 구분 없이 꺼짐이다. 변경 직후 구형 브라우저 탭은 이전 코드를 실행할 수 있으나 새 API 요청은 서버 게이트를 따른다. 캐시를 지우거나 발행 이력·저장본을 삭제하지 않는다.

## 단계별 확인

1. 새 배포의 `/api/auth/me` 응답에서 `features` 값과 운영 설정이 일치하는지 본다. 개인 매물 접근은 별도 인증으로 계속 확인한다.
2. 지역 판정 근거·반대 근거, 매물 리포트, 후보 발견, 선택형 설명을 실제 계정으로 순서대로 연다. 열람만으로 유료 모델 호출이 없어야 한다.
3. 장애 시 관련 스위치만 `0`으로 바꾸고 재배포한다. 새 페이지에서 안내·대체 경로가 보이는지, 신규 API가 `503`인지 확인한다. 보안·지역 식별·오판 방지 수정은 되돌리지 않는다.
4. 원인·원천 기준일·비용/지연을 기록하고 해당 스위치만 다시 `1`로 복구한다. 기존 발행 판정과 개인 기록은 그대로 둔다.

Nick 채팅 진입점과 관련 플래그·사용량 표시는 제거했으며 어떤 스위치로도 다시 켜지지 않는다. 기존 채팅 URL은 오래 열린 탭의 유료 호출을 막기 위해 `410`만 반환하고, 저장된 메모리의 삭제 API는 유지한다. 초보자 과업과 리포트 충분성 검사는 여전히 출시 완료 조건이다. 이 문서는 롤백 절차이지 운영 복원 리허설의 증거가 아니다.
