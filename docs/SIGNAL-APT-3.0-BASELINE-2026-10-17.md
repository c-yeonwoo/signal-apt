# Signal APT 3.0 기준선 — 2026-10-17

이 기록은 [3.0 로드맵](SIGNAL-APT-3.0-ROADMAP.md)의 0단계 중 **재현 가능한 코드·운영 화면 감사**다. 운영 화면은 2026-10-17 약 10:20 KST에 지정 개인 계정의 Chrome 데스크톱에서 읽기 전용으로 확인했다. 한 계정·한 시점의 표본이며 전체 지역·매물의 정확성이나 정상 가동률을 증명하지 않는다. 개인 연락처·재산 정보와 원천 응답 본문은 기록하지 않았다.

## 화면과 문서 충돌

- 홈 첫 화면에서 텔레그램 연결 안내와 긴 관심단지 목록이 주요 변화·오늘 할 일보다 앞선다. 관심단지 일부에는 실거래 미수집/장기 지연이 이미 표시된다. 따라서 카드 순서 변경 전 데이터 없음·오래됨 상태를 유지해야 한다.
- 데이터 신선도 패널은 이전에는 모든 일반 원천을 `8일 이내/9~31일/32일 이상`으로 같은 색에 묶었다. 이 기준은 하루 갱신과 개별 호가 7일 유효성을 설명하지 못한다. 이번 변경은 개인 매물 세 원천을 별도로 표시한다. 다른 원천의 단순 파일 시각 색상은 후속 감사 대상이다.
- [기존 디자인 시스템](../DESIGN.md)의 Nick 진입점·예전 상단 메뉴는 실제 UI 및 [2.0 설계](SIGNAL-APT-2.0-DESIGN.md)의 채팅 제거 결정과 충돌한다. 오래된 규칙을 3.0 구현 지시로 사용하지 않고, 1단계에서 현행 토큰·메뉴·모바일 상태를 기준으로 정리한다.

## 검증 상태와 다음 조사

코드로는 캐시 실패 시 직전 결과 보존, 원천 접근 권한 분리, 동일 지역/면적 근거 분리의 회귀가 있다. 이는 **운영 원천 전체의 품질 증거가 아니다**. 이번 화면 관찰도 성능 측정이 아니다. Chrome DevTools 추적 도구는 기존 프로필 충돌로 시작하지 못했으므로 Core Web Vitals, warm 발견/기본 리포트 p95, 모바일 주요 내용 표시 시간은 미측정이다. 초보 구매자 5명의 과업 관찰, 실기기 터치·키보드 검사, 운영 DB 지역 감사, 실제 백업 복원과 롤백 리허설도 수행하지 않았다.

다음 구현 전에 또는 병행해 다음 표본을 고정한다: 일반매물·급매·찐매물의 원천별 성공/실패/제한 지역, 관심단지별 수집 범위, `0건`과 필터 제외의 대표 시나리오, 360~390px 및 데스크톱 후보 두 개 비교 동선. 성능은 테스트 장치·네트워크·계정·원천 건수·cold/warm 조건을 기록해 재측정하고, 접근할 수 없는 운영 증거는 담당자 확인 전까지 미검증으로 둔다.
