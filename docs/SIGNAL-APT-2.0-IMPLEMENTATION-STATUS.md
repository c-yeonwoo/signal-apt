# Signal APT 2.0 구현 현황

2026-10-03 첫 구현 단위. 설계 정본은 [제품·시스템 설계](SIGNAL-APT-2.0-DESIGN.md), 남은 패키지는 [구현 인계](SIGNAL-APT-2.0-IMPLEMENTATION.md)를 따른다. 이 문서는 전체 2.0 완료 선언이 아니다.

## 이번 단위에 포함

- KB DataHub 신규 수집에서 서울·인천 중구를 분리한다. 기존 이름 충돌 캐시는 판정 보류하며 원천을 소급 복원한 것으로 취급하지 않는다.
- raw 시그널을 보존하면서 최근 4주 가격·심리·전세 자료의 결측, 기준일, 지역 코드, 가격 방향 충돌을 별도 안전 판정으로 기록한다. 지역 지도·목록·관심 카드의 주 배지도 보류 상태를 따른다.
- 발행 판정은 append-only 테이블에 보존하고 지역 리포트에 이전 발행과 현재 값·방법·원천 수정·신선도 변화를 구분한다.
- 독립 매물 리포트를 Nick 자동 호출 없이 열고, 현재 수집분의 가격·장단점·미확인 항목과 비교함을 연결한다. 기존 Nick은 사용자가 명시적으로 요청할 때만 유지한다.
- 개인 계정에만 일반·급매·찐매물 탐색을 허용한다. 호가·면적·지역 필수 조건의 부합/미확인/초과를 나누고, 지역 선호와 단지 다양성을 적용한다. 사용자 판단 기록은 개별 수정 버전으로 저장한다.

## 검증

합성·격리 데이터에서 Python 전체 576개, UI 런타임 14개, Chromium 360px 브라우저 회귀 통과. 실서비스 계정의 원천 수집 상태·실제 지도 타일·Railway 배포·DB 백업 복구·p95 지연은 이 테스트가 검증하지 않는다.

## 후속 단위: 시그널 작업 공간

- 좁은 화면에서 지역 목록·판정 근거·가격·수급 추세·지도를 한 번에 펼치지 않는다. 선택 지역의 판정 근거를 기본으로 보여 주고, 추세·지도는 별도 탭에서 연다.
- 모바일 지역 목록은 닫을 수 있는 패널로 분리하고 Escape·포커스 복귀·탭 키 순환을 지원한다. 헤더와 하위 탐색을 시그널 화면에서 간결하게 표시한다.
- 추세 시계열은 탭을 열 때만 요청하고, 지역 전환 중 이전 응답이 도착해도 새 지역 차트에 덮어쓰지 않는다. 지도 역시 해당 탭에서만 그린다.
- 합성 Chromium 360px·390px·데스크톱에서 패널 경계, 키보드 탐색, 지역 전환과 지연 로딩을 확인했다. 실제 사용자 과업과 운영 지도 타일 검증은 아직 남아 있다.

## 후속 단위: 매물 화면의 안전 판정

- 통합 매물 정규화에서 원시 등급은 감사용으로 남기고, 카드의 시그널과 타이밍 점수는 당일 지역 안전 판정을 사용한다. 지역 매핑이 없거나 판정 계산에 실패하면 매수 등급으로 되돌리지 않고 `HELD`로 표시한다.
- 급매·일반매물·청약·경매·관심지역 등 기존 화면의 지역 배지와 BUY+ 필터는 현재 안전 판정을 참조한다. 이전 버전의 브라우저 시그널 캐시는 재사용하지 않고, 날짜가 바뀌면 다시 확인한다.
- 합성 데이터에서 원시 `BUY`의 보류 승격 방지, 안전 판정 실패 시 보류, 화면 필터·배지 동작을 확인했다. 과거 시그널 변동 알림은 과거 원시 판정 기록이라 재작성하지 않았다.

## 후속 단위: KB 지역 식별 출처 검증

- 새 DataHub 수집의 지역명·코드 충돌을 감지하면 캐시 갱신을 중단한다. parquet와 코드 파일의 해시를 묶은 식별 증명을 저장하며, 파일이 바뀌거나 증명이 없는 과거 캐시는 검증된 수집분으로 취급하지 않는다.
- 이름이 겹치는 서울·인천 중구는 코드 문자열만 남은 구 캐시에서 판정을 보류한다. 검증된 새 수집분만 `kb:<code>` ID로 리포트를 조회할 수 있고, 기존 이름 경로는 호환을 위해 남겨 둔다. 발행 이력도 검증 전후 ID를 분리해 과거 중구 자료를 소급 병합하지 않는다.
- 원천 상태 API에 KB 식별 증명 여부를 표시한다. 합성 테스트는 코드 충돌, 증명 파일 누락·변조, 코드 경로 거부와 정상 조회를 확인한다. 운영 캐시 전체의 과거 출처 복원이나 실제 Railway 파일 검사는 수행하지 않았다.

## 다음 단계와 출시 제한

1. 지역 식별을 코드 중심으로 모든 소비자에 이행하고 운영 캐시의 이름 충돌 범위를 점검한다. 현재는 새 수집 증명과 지역 리포트 코드 경로를 추가한 단계이며, 매물·관심·알림 저장 키의 전환과 과거 자료의 원천별 복구는 아직 남아 있다. 같은 이름의 다른 지역과 과거 데이터는 검증 없이 병합하지 않는다.
2. 시그널 산출 경로마다 보류 상태를 적용한다. 지역 지도·통합 매물·주요 목록 배지는 안전 상태를 따르지만, 단지 고유 등급과 과거 알림 기록, 별도 전략·추천 API는 아직 원시 등급 의미를 감사해야 한다.
3. 매물 조건을 기존 자금 엔진·통근·입주 시점까지 확장하고 선호 coverage, 안정적 페이지네이션, 원천 실패별 빈 상태를 완성한다. 현재 월 부담 조건은 입력 자료가 없으면 미확인으로 남긴다.
4. 리포트 공유 경로·불변 스냅샷·부분 실패·운영 캐시를 정리하고, 선택형 맥락 질문을 붙인다. 핵심 질문을 새 리포트에서 해결할 수 있음을 검증하기 전 Nick 전역 진입을 숨기지 않는다.
5. 운영 DB 백업·복구, 원천 최신일, 타일 표시, 모바일 390px/데스크톱 및 실사용 과업을 확인하고 단계별 출시/되돌리기 기준을 적용한다.

미래 상승 확률·투자 수익률은 이번 판정이나 테스트에서 검증되지 않았다. 현재 시그널은 동시점 지역 관측이며 매물 가격의 적정성이나 매수 결정을 보증하지 않는다.
